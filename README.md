# Shule Lite

School exam results management platform (PHP + MariaDB) for Tanzanian schools —
school setup, exam entry, results processing, and academic reporting.

## Development phases

- **Phase 1** — Auth & core entities
- **Phase 2** — Plans, packages, directors (versioned edit, deactivate/reactivate)
- **Phase 3** — School Setup — classes, streams, subjects, teachers, academic calendar
